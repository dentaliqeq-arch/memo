동기화 설정

메모는 기본으로 이 기기 브라우저에 저장됩니다. 아래에 GitHub 토큰을 넣으면 비공개 Gist에 보관되어, 핸드폰과 노트북이 같은 메모를 봅니다.

  1. github.com/settings/tokens → Generate new token (classic)
  2. 권한은 gist 하나만 체크
  3. 만들어진 토큰(ghp_…)을 아래에 붙여넣기

토큰은 이 브라우저에만 저장되고 GitHub 외에는 전송되지 않습니다. 메모 본문은 비공개 Gist에 들어갑니다.
